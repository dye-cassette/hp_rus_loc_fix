# Russian Localization Fix для House Party

Вычитанный русский перевод всей игры и дополнений, кириллические шрифты,
переведённый интерфейс. Плагин BepInEx 6 — файлы игры не меняются.

**Скачать:** раздел [Releases](../../releases/latest) справа.

Установка: распакуй архив в папку с House Party.exe и выбери в игре язык «Русский».
Подробная инструкция — в файле README_HousePartyRU.txt внутри архива.
